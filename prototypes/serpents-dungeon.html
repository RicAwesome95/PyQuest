Code Builder edition: build Python programs from blocks to complete quests, defeat the monsters, beat the bosses.

Every quest is generated on the spot from code templates, at any level from 1 to 15. You get the program's lines as shuffled blocks (plus a few decoys) and must build a program that prints the quest's target output, with the right order and indentation. A small neural network (MLP) predicts whether you will complete a quest on your first run without a hint, and in Adaptive mode it generates quests where it expects about an 85% chance of success.

3 floors · each floor has 4 quest rooms and a boss · 3 runs and 1 hint per quest · a failed quest lets the monster hit you (5 hearts) · fast first-run builds land critical hits, streaks build a combo · earn coins and XP, then spend them at the camp between floors.

Thesis evaluation

      
MLP vs. logistic regression vs. Bayesian Knowledge Tracing vs. a rule-based method, on generated Python challenges.

      

        Setup. Simulated learners only (allowed for Thesis 1): 320 learners with different skill levels play 30 generated challenges each, under a mix of difficulty policies.
        Learners are split 80/20 into train and test. Every model gets the same features, the same split and the same metrics.
        Thesis 2 repeats these tests on real gameplay, plus a pre-test and the in-game difficulty survey to check that the difficulty matches each student.
