An adaptive Python code dungeon. Trace the code to cast your spell, defeat the monsters, beat the bosses.

Every challenge is generated on the spot from code templates, at any level from 1 to 15. A small neural network (MLP) watches how you play and predicts whether you will solve a challenge on your first try without a hint. In Adaptive mode the game generates challenges where it expects about an 85% chance of success, so strong players get harder and harder code and struggling players get easier code.

3 floors · each floor has 4 monster rooms and a boss · the right output casts your spell, a wrong one lets the monster hit you (5 hearts) · fast answers land critical hits, first-try streaks build a combo · earn coins and XP, then spend coins at the camp between floors.

Thesis evaluation

      
MLP vs. logistic regression vs. Bayesian Knowledge Tracing vs. a rule-based method, on generated Python challenges.

      

        Setup. Simulated learners only (allowed for Thesis 1): 320 learners with different skill levels play 30 generated challenges each, under a mix of difficulty policies.
        Learners are split 80/20 into train and test. Every model gets the same features, the same split and the same metrics.
        Thesis 2 repeats these tests on real gameplay, plus a pre-test and the in-game difficulty survey to check that the difficulty matches each student.
